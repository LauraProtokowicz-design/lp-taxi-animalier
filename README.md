# LP Taxi Animalier — version indépendante v2

Cette version est une PWA autonome : aucun appel à Claude, React, Babel, Lucide ou autre bibliothèque externe n'est nécessaire pour démarrer l'application.

Les données sont enregistrées localement dans le navigateur de l'iPhone via localStorage.

## Déploiement Netlify
1. Décompresser le ZIP.
2. Déposer le dossier sur Netlify Drop.
3. Ouvrir l'URL netlify.app.
4. Sur iPhone : Safari → Partager → Sur l'écran d'accueil.

Cette version comprend Agenda, Demandes, Clients, Devis, Factures, Chiffre d'affaires et Tarifs.
